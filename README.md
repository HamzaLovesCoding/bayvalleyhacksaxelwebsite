# Axel website — Bay Valley Hacks

Partial source snapshot of the Axel assistive robot arm website.

This initial snapshot contains the Next.js/TypeScript project configuration, dependency lockfile, arm inverse kinematics, and shared tray layout. The website pages, components, and visual assets remain in the local development project and are not included yet, so this snapshot is not a runnable website.

Commit timestamps record when snapshots are published, not when all included code was originally written.
